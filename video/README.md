# Video 30 giây: CodeOwn gọi AI thật

Quay màn hình VS Code với extension CodeOwn trên `demo-repo`: AI viết code, commit, CodeOwn mở Check và hỏi về đúng các dòng AI viết, Grader chấm vòng 1 "Chưa hiểu" kèm gợi ý. Gọi model thật, không dựng lại output bằng tay.
